# Kairos Solo

A to-do app for Windows: tasks, projects and areas, calendar, habits, focus timer, weekly review.
Everything stays on your PC: no account, no server, no tracking.

Made by Amrou H.

## Download

**[Download Kairos Solo for Windows](https://github.com/AmrouHab/kairos-releases/releases/latest/download/Kairos-Solo-Setup.exe)** (always the newest version)

Windows may show "Windows protected your PC" the first time, because the installer isn't signed
with a paid certificate: click **More info → Run anyway**. You only see this once.

## Updates

Kairos Solo checks for a new version every few hours and offers **Restart to update**.

## Your data

- Your tasks live only on this PC.
- Every day Kairos Solo saves a copy to `Documents\Kairos Backups` (the last 14 are kept).
- To move to another PC or recover: Settings → Export and restore → Restore from JSON, then pick one of those files.
- Keep a copy somewhere else too (a USB key or a cloud folder): if the disk dies, the backups go with it.
